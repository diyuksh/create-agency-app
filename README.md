# 🚀 Create Agency App

Scaffold a high-performance Next.js template tailored for your agency in seconds. Built with Go and Bubble Tea for an incredible, zero-dependency TUI experience.

![Demo](https://via.placeholder.com/800x400?text=Bubble+Tea+TUI+Demo)

## Why use this?
When building sites for agency clients, you often need the same stack: Next.js, Tailwind, Shadcn/UI, and varying integrations like Sanity or Shopify. This CLI bundles a premium, production-ready template via `go:embed`, stripping out what you don't select to give you a pristine starting point.

## Installation & Usage
```bash
curl -fsSL http://template.sar.ga/ | bash
```
Follow the interactive prompts to select your stack.

## Upgrading
If you already scaffolded an app, you can seamlessly update its infrastructure scripts without touching your application code:
```bash
./create-agency-app upgrade
```
